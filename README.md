Number-Guessing Game 🎮
A simple, interactive, and beautifully styled Number-Guessing Game built with HTML, CSS, and JavaScript. This project is part of a series of web development practice projects designed to sharpen frontend logic and DOM manipulation skills.

✨ Features
Interactive Gameplay: Guess a randomly generated number between 1 and 100.

Attempt Tracking: Keeps track of your remaining attempts (up to 10 tries) and displays previous guesses instantly.

Dynamic Feedback: Provides real-time messages (e.g., correct guess, game over, or hints).

Reset Functionality: Easily start a fresh game at any time with the "New Game" button.

Responsive Design: Clean and modern user interface styled for a smooth experience.

🛠️ Tech Stack
HTML5: Markup structure and layout.

CSS3: Styling, typography, and layout responsiveness.

JavaScript (ES6): Core game logic, state management, and DOM manipulation.
